# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I explored the Ubuntu Linux system, created a new user account, gathered system information, organized files and directories, and created a GitHub repository for my Cloud Computing Portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Demonstrate proper documentation practices.

## Activities Performed

1. Launched Ubuntu 24.04 using the KillerCoda Playground.
2. Created a new Linux user with Bash, a home directory, and sudo access.
3. Checked the current username, working directory, and hostname.
4. Gathered Linux distribution, kernel, CPU, memory, and disk information.
5. Created folders for Notes, Reports, and Screenshots.
6. Created an about-me.md file.
7. Created a public GitHub repository for my Cloud Computing Portfolio.
8. Organized the required laboratory files and folders.
9. Documented the activity using Markdown.
